# Grey116.github.io

Personal homepage for Jiawei Lin, built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and intended for deployment at <https://Grey116.github.io/>.

The original al-folio README is kept in [`AL-FOLIO_README.md`](AL-FOLIO_README.md). Theme customization notes are in [`CUSTOMIZE.md`](CUSTOMIZE.md).

## Local preview

The recommended local workflow is Docker:

```bash
docker-compose up
```

GitHub Pages deployment is handled by the included GitHub Actions workflow in `.github/workflows/deploy.yml`.
